# PCP 0.4.1 — voice, group actions and replay identities

AstrBot's existing speech preprocessing supplies text to OpenClaw. The relay
also captures event-owned voice WAVs after STT replaces Record with Plain,
normalizes them to mono 16 kHz PCM, and signs them with the turn. PCP validates
and strips WAV metadata, stores the audio under the same session authorization,
and renders a player in message history. Up to three minutes per voice and six
MiB total media per turn; images/GIFs continue to work. Voice transcripts are
ordinary searchable message text. No raw audio is mislabeled as an image input.

`deploy/speech.compose.yaml` runs pinned faster-whisper with its multilingual
base model, CPU int8, persistent model storage and a private API key. The local
OpenAI-compatible transcription endpoint replaces exhausted cloud STT credentials
without changing the provider's transcript contract. Model/download files stay
under DockerVolumes/pcp/speech. Only loopback is published.

`deploy/executor.compose.yaml` runs a trusted, grant-checking container launcher.
It alone has the Docker control socket; action containers never receive it.
Every call revalidates PCP's live grant. Action containers run as uid 1000,
with read-only root, no network, no capabilities, no-new-privileges, one CPU,
256 MiB RAM, 64 processes, 30-second timeout and capped logs. Only the chat's
hashed workspace is mounted. The agent dashboard list editor provisions
minimal group agents with only PCP context/image tools and `pcp_execute`.
Native filesystem/process/session tools and elevated execution are denied.
Groups retain their own PCP context even when the sender is an administrator.
The live group list is intentionally empty.

Migration 016 adds a message identity ledger. First ID-based replays match
legacy messages by exact role/content/provider/timestamp and record aliases;
message IDs, ordinals, contents, timestamps and attachments are not modified.
Repeated identical messages retain distinct identities. New messages remain
append-only. The OpenCode session manager registers projects/workspaces and
sends versioned task context and stable message IDs with redacted text.

Deployment: initialize host-backed `pcp/speech/models`, speech credentials,
and `pcp/group-workspaces`; build/start the two Compose sidecars. Sync the
AstrBot and openclaw-pcp plugins using existing deployment helpers. Point the
AstrBot Whisper provider at the local speech endpoint with its private key.
Keep database/media/config backups and rollback images. No separate Unix users
or forge-admin changes are required for these action containers.
