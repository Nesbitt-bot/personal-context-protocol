# v0.2.1

Identity phase 2: service credentials, turn grants, sync and recall (see
`docs/service-sync.md`).

- Admin-minted `pcps_` service credentials for channel plugins: hashed,
  revocable, bounded to principal prefixes, accepted only on
  `/api/v1/service/*` (never admin, UI login or agent token).
- Server-side turn grants keyed by (credential, OpenClaw session key) with a
  readable session set and TTL: linked DMs read the owner's sessions across
  channels, unlinked DMs and groups read only their own session.
- `POST /service/sync` appends a turn to the grant's home session,
  idempotent by external key; `POST /service/recall` and `/service/search`
  read only within the grant. Optional claim code on unlinked DM grants.
- Migration 012 (additive, idempotent).
