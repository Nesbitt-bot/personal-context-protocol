# v0.4.4

Global scoped tokens now retain the **Manage projects** permission selected
in the token manager. The request validation schema previously stripped this
field before the token was saved, causing project registration, task creation,
and identity-based session sync to fail with `403`.

Create a replacement global token after deploying this fix. Existing tokens
retain their permissions, and folder/session tokens remain unable to manage
projects. The token fix requires no database migration.

This release also includes the four previously local Spark commits for
private session search, account-menu/profile navigation, retrieval tests, and
search docs. Profile pictures use additive migration 024; existing users and
sessions are preserved. Deployment remains owned by the Jenkins webhook.
