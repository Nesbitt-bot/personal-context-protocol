# v0.3.0

Design Phase 4: the AstrBot path through a loopback PCP broker, plus
deployment hygiene.

- **PCP broker** (`broker/server.js`, compose service `broker`, same image):
  loopback-only, holds the OpenClaw gateway token, fails closed. PCP verifies
  the AstrBot ingress credential, the HMAC over the raw body, a ±120 s window
  and a nonce/platform-message replay ledger (`401` otherwise); derives the
  principal from the stamp; picks the session (DM: the sender's, group: the
  group's) and the agent (`relay`, or `relay-owner` for a verified owner DM);
  injects a "Verified sender (PCP-attested)" block and bounded context; records
  the turn. See `docs/broker.md`.
- **Credential kinds** (migration 014): `channel`, `ingress`, `broker`; the
  `astrbot:` prefix is reserved for ingress. Broker grants keyed
  `pcp:<grt_ 48 hex>`, readable (never writable) by the broker's delegate,
  the openclaw-pcp credential.
- **thirdparty/astrbot_plugin_pcp_relay** (new): identity stamp + provider
  adapter `pcp_relay`, standard library only.
- **thirdparty/openclaw-pcp 0.2.0**: tools work for broker turns with the
  plugin's own credential; broker turns skip local grants, context, sync and
  claims; the HTTP backstop covers `pcp:grt_…` sessions.
- **Operator CLI**: `--kind ingress|broker`, `--delegate`, `--signing-key-out`;
  `user list`; `identity link|unlink|list`.
- **Idempotent appends**: a timestamped message already in the session (same
  role, content, `provider_timestamp`) is not stored again, under a session
  lock, so the OpenCode session-manager cannot duplicate turns when it
  replays from a stale cursor.
- **Storage**: PostgreSQL data in a host bind mount (`PCP_POSTGRES_DATA_DIR`)
  with a guard that refuses to start an empty cluster while the legacy volume
  still has data (`deploy/jenkins/check_storage.sh`).
- **Jenkins**: database tests on a throwaway PostgreSQL, plugin test suites,
  storage-guard tests, and a post-deploy sync of both channel plugins (backup,
  restart, health and channel checks, automatic restore).
