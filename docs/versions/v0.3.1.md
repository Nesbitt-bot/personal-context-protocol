# v0.3.1

- **Fix: broker turns ran as OpenClaw's default agent.** OpenClaw takes the
  run's agent from an `agent:<id>:` session-key prefix and falls back to its
  default agent (`main`) for any other explicit `x-openclaw-session-key`,
  ignoring the `openclaw/<agent>` model. With the 0.3.0 key `pcp:<grant id>`,
  every AstrBot turn therefore ran as `main` (owner workspace and memory in
  context; non-`pcp_*` tools were still refused by the openclaw-pcp HTTP
  backstop). PCP now returns `agent:<agent>:pcp:<grant id>`, the broker also
  sends `x-openclaw-agent-id` and refuses a prepared turn whose agent, model
  and key disagree. Found by the production check before any real traffic;
  the broker was stopped (fail closed) until this release.
- astrbot_plugin_pcp_relay 0.1.1: other plugins' sessionless LLM calls get an
  error response and never consume the pending turn or stop the event.
